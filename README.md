# Танковый чат

Многопользовательская игра на FastAPI с общей комнатой чата. Сервер хранит состояние только в памяти одного процесса; база данных и постоянное соединение с клиентами не используются.

## Запуск

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
uvicorn app:app --host 0.0.0.0 --port 8000
```

Откройте `http://localhost:8000` для игрового поля или `http://localhost:8000/admin` для управления комнатами. Админка использует HTTP Basic: логин `admin`, пароль `tankcity` (константы `ADMIN_USERNAME` и `ADMIN_PASSWORD` в `app.py`). Замените эти значения перед использованием в сети; не выставляйте сервер с демонстрационными реквизитами в публичный интернет.

В админке создайте комнату. Браузер только показывает поле и чат; отправлять сообщения и команды из него нельзя. Для входа используйте терминальный клиент и отправьте сообщение `войти НОМЕР_КОМНАТЫ ИМЯ`, например `войти 1 Анна`. Первый игрок запускает 15-секундный отсчёт, новые участники могут регистрироваться во время отсчёта. Каждый раунд содержит 20 танков; все незанятые танки автоматически управляются ботами. Раунд начинается по окончании отсчёта и завершается после уничтожения всех танков.

Команды управления: `вверх`, `вниз`, `влево`, `вправо`, `выстрел`. Игрок также может зарегистрироваться запросом `POST /api/rooms/{id}/join` с JSON `{"name":"Анна"}`. Неактивный 30 секунд игрок передаёт танк боту.

## API

- `GET /api/rooms` — список комнат и их статусов.
- `POST /api/rooms` — создать комнату, только администратор; JSON `{"name":"Комната"}`.
- `DELETE /api/rooms/{id}` — удалить комнату, только администратор.
- `POST /api/rooms/{id}/join` — зарегистрировать игрока на раунд.
- `POST /api/rooms/{id}/messages` — отправить сообщение; JSON `{"sender":"Анна","text":"Привет"}`.
- `POST /api/rooms/{id}/commands` — отправить одну из пяти команд управления с тем же JSON-форматом.
- `GET /api/rooms/{id}/state` — полное состояние поля, танков, снарядов, блоков, бонусов и последних сообщений.

API-документация FastAPI доступна по `/docs`. Игровая симуляция работает с частотой 15 тиков/с; браузер опрашивает состояние 10 раз/с. Запустите терминальный клиент без параметров:

```sh
python terminal_client.py
```

Клиент использует адрес сервера из константы `SERVER_URL`, запрашивает номер комнаты и имя, затем читает сообщения/команды из stdin. Команда `войти НОМЕР ИМЯ` должна содержать указанный номер комнаты и имя отправителя, иначе сервер вернёт ошибку. При успешной отправке клиент ничего не выводит; сетевые ошибки и ошибки сервера отображаются в stderr.

## Игровые правила

Карта — фиксированная 13×13 из задания. Снаряды проходят через воду и кусты, разрушают кирпич после двух попаданий и останавливаются о сталь и базу. Бонус с вероятностью 30% появляется после уничтожения танка: звезда повышает уровень и лимит снарядов до двух, шлем защищает 8 секунд, часы замораживают остальные танки на 5 секунд. Боты раз в секунду выбирают ближайший живой танк и ищут к нему путь по карте.

Сообщения и состояние доступны только в памяти процесса; чат хранит последние 200 сообщений комнаты для браузерного отображения. При перезапуске сервера комнаты и раунды теряются. Запуск нескольких рабочих процессов не поддерживается.
