# Танковый чат

Многопользовательская игра на FastAPI с общей комнатой чата. Сервер хранит состояние только в памяти одного процесса; база данных и постоянное соединение с клиентами не используются.

## Запуск

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```

С помощью файла `url_server.py` можно настроить адрес и порт сервера. Эти данные будут использоваться для запуска сервера и подключения клиента.

Откройте `http://localhost:8000` для игрового поля и общего чата.

Игра сразу работает в одной общей комнате, число игроков и танков не ограничено. Новые игроки могут подключаться в любой момент, отправив `войти ИМЯ`, например `войти Анна`. Даже если остаётся один или не остаётся живых танков, раунд не завершается. За уничтожение танков начисляются убийства.

Команды управления: `вверх`, `вниз`, `влево`, `вправо`, `выстрел`. Игрок также может зарегистрироваться запросом `POST /api/join` с JSON `{"name":"Анна"}`. Неактивный 30 секунд игрок передаёт танк боту.

## API

- `POST /api/join` — зарегистрировать игрока; JSON `{"name":"Анна"}`.
- `POST /api/messages` — отправить сообщение; JSON `{"sender":"Анна","text":"Привет"}`.
- `POST /api/commands` — отправить одну из пяти команд управления с тем же JSON-форматом.
- `GET /api/state?after=VERSION&get_messages=false` — полное состояние игры; если версия не изменилась, запрос ждёт следующего события. Флаг, сообщающий нужно ли отправлять сообщения. 

API-документация FastAPI доступна по `/docs`. Постоянного игрового тика нет: команды применяются сразу при получении, а таймерные события для ботов, бонусов и снарядов обрабатываются по ближайшему дедлайну. Браузер получает начальное состояние, затем держит long-poll запрос открытым и отправляет следующий сразу после события игры.

Клиент управления с клавиатуры запускается так:

```sh
python tkinter_client.py
```

Введите имя и нажмите «Подключиться». Стрелки управляют танком, пробел стреляет. При уничтожении танка клиент покажет уведомление и отключится; для возвращения нажмите «Подключиться» ещё раз. Адрес сервера по умолчанию `http://193.124.115.164:8000`; для смены адреса или порта измените `SERVER_URL` в `tkinter_client.py`.

## Игровые правила

Карта — фиксированная 26×13 (в 2 раза шире исходной). Вода не является непроходимым препятствием: танки могут по ней двигаться, а снаряды проходят сквозь. Снаряды уничтожают друг друга при столкновении, проходят через кусты, разрушают кирпич после двух попаданий и останавливаются о сталь и базу. Танки игроков добавляются без ограничения; боты появляются волнами, а после 30 секунд бездействия танк игрока переходит под управление бота. Бонус с вероятностью 30% появляется после уничтожения танка: звезда повышает уровень и лимит снарядов до двух, шлем защищает 8 секунд, часы замораживают остальные танки на 5 секунд.

Сообщения и состояние доступны только в памяти процесса; чат хранит последние 200 сообщений комнаты для браузерного отображения. При перезапуске сервера комнаты и раунды теряются. Запуск нескольких рабочих процессов не поддерживается.
